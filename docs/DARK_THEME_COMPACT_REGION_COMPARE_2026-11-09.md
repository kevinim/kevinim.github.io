# 지역 비교 접기 및 라이트/다크 모드 — 2026-11-09

## 사용자 화면
- '지역 나란히 비교'는 기본 **접힘**. 제목, 선택 ZIP 간단 요약, '열기'만 노출.
- 제목 전체는 표준 HTML `<details><summary>`로 키보드 Enter/Space 및 스크린리더 지원. 펼쳤을 때에만 원래 2–3개 ZIP 비교 표와 선택 버튼 노출.
- 데이터 호출과 큰 비교표 재구성도 **최초 펼침 후** 시작하므로, 지도 첫 로드와 화면 높이에 부담을 최소화.
- 새 `다크 모드 / 일반 모드` 전환 버튼은 최상단 브랜드 헤더 오른쪽에 배치. 최초 상태는 일반 모드, 선택은 같은 브라우저에서 `localStorage`의 `tx-dashboard-theme-v1` 한 항목에 저장.
- 차단된 사설 브라우저 스토리지에서도 현재 화면 전환은 작동. 다른 탭의 변경은 저장소 이벤트로 동기화.
- 외부 서비스 호출, 개인화 주소, 쿠키/인증, 백엔드 변경 없음.
