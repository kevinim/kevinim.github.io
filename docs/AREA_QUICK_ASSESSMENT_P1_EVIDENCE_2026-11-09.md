## UI 원칙
- **학교:** 2026 TEA 예비 등급 + 현재 ZIP에 위치한 캠퍼스. 주소 배정 학교 아님. ZIP 다각형 누락은 0곳이 아닌 확인 필요로 표시.
- **자연재해:** NOAA NCEI 2024–25 카운티형 보고 사건수(우박·홍수). FEMA 2025 인구조사구역 상대 위험 지도는 **별개**이고, 클릭 시 NOAA 상세 패널도 열며 가능한 경우 해당 카운티를 자동 선택.
- **범죄:** FBI NIBRS 2025 도시 전체 신고율. 12개월 모두 보고됐고 선택 ZIP에 주된 관할 도시 비율이 50% 이상일 때만 표시. 다수 관할 ZIP(예: 75056)은 한 도시 지표로 단정하지 않음.
- **통근:** 현재 사용자가 기존 통근 패널에서 계산한 목적지의 ZIP 대표점 결과만 표시. 사전 저장된 개인 직장 데이터 사용하지 않음.
- **상태:** 자료 확인 / 확인 중 / 자료 없음 / 관할 혼재 등을 구분하고, 색만으로 판단 상태를 전달하지 않음.
- 지도 이동은 기존 레이어 토글을 활용하고 학교 배정·핀 알고리즘 및 기존 보안 CSP는 변경하지 않음.
