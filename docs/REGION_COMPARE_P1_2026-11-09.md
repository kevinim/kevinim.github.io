# P1-2: 2–3개 ZIP 지역 나란히 비교 (2026-11-09)

## 사용자 경험
- 기존 **지역 빠른 점검**과 **동네 지도** 사이에 나란히 비교 섹션을 추가. 기본 선택은 Allen 75013, Frisco 75034, West Plano 75093.
- 후보 A/B/C의 ZIP 선택, 세 번째 후보 제외/추가, **현재 지도 지역 넣기**, **지도에서 보기**를 제공.
- 선택을 변경해도 주택 주소 검색 및 기존 주소 비교함은 변경하지 않음. 같은 ZIP의 중복 선택을 막음.
- 데스크톱: 2~3개 비교열, 모바일: 표 영역에서만 가로 스크롤. 표준 키보드/스크린리더 요소 사용.
- 모든 셀은 `textContent` 기반 DOM 생성(외부 문자열을 HTML로 해석하지 않음).

## 격리·품질 게이트
- **기존 `지역 전체 비교` 표와 주택 주소 3개 비교**는 수정하지 않음.
- 기존 학교 마커/배정선/주소 지오코딩/Leaflet 지도 갱신 함수는 수정하지 않음.
- 현행 CSP 및 공개 프리뷰 개인정보 제거 로직은 수정하지 않음. 새 모듈에 직장 주소, 인증, 개인 데이터 저장 없음.
- 새로운 `features/region-compare-core.js`, `features/region-compare.js`, `features/region-compare.css`만 추가하고 `index.html`에 로컬 정적 참조를 추가.
- `node --test tests/region-compare.test.cjs`에 수치·지리적 범위·누락 검사, 실제 Chromium 390/1280에서 지역 선택·중복·두/세 후보 전환·지도 버튼·Allen 마커를 확인. 전체 보안/데이터 CI가 통과해야 병합.
- 렌트, 부동산 월비용, 보험/HOA 및 백엔드는 명시적으로 제외.
